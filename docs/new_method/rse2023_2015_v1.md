# RSE2023 2015 Inventory Workflow

Historical smoke-stage artifacts from the first pilot passes were archived during
cleanup. If you need those exact paths, see:

- `archive/2026-03-18_whole_house_cleanup/new_method_smoke/`

This workflow keeps the 2015 CPI product in the same methodological family as
the 2000 and 2021 anchor inventories derived from
`docs/references/chen_et_al/Chen-mapping-center-pivots.pdf`.

## 1. Normalize Anchor Truth

Build normalized 2000/2021 anchor packages plus stable/change/background strata.

```bash
python cpis.py qa prepare-anchor-truth \
  --truth-2000 Africa_CPIS-shp/Africa_CPIS_2000.shp \
  --truth-2021 Africa_CPIS-shp/Africa_CPIS_2021.shp \
  --out-root runs/new_method/rse2023_2015_v1/anchor_truth
```

Outputs:

- `anchors/anchor_2000_normalized.gpkg`
- `anchors/anchor_2021_normalized.gpkg`
- `overlays/stable_pivots.gpkg`
- `overlays/change_zones.gpkg`
- `overlays/stable_background_cells.gpkg`
- `overlays/stable_background_points.gpkg`
- `overlays/study_area.gpkg`
- `summary.json`

## 2. Export Full-Year 2015 Imagery

Use the Landsat GEE exporter in paper-compatible 4-band mode.

For arid sub-Saharan Africa only, use the SSA arid-region shapefile and start
tasks in batches rather than queueing the full year in one shot.

```bash
python cpis.py gee export-year \
  --year 2015 \
  --region SSA_Arid_by_Country-shp/SSA_Arid_by_Country.shp \
  --feature-contract paper_rgbnir_v1 \
  --run-dir runs/new_method/rse2023_2015_v1/exports/2015_ssa \
  --manifest runs/new_method/rse2023_2015_v1/exports/2015_ssa/export_manifest.json \
  --drive-folder CPIS_RSE2023_2015_RGBNIR_SSA
```

The manifest stores the selected feature contract and band names.

Then start tasks in batches, for example 100 at a time:

```bash
python cpis.py gee export-year \
  --year 2015 \
  --region SSA_Arid_by_Country-shp/SSA_Arid_by_Country.shp \
  --feature-contract paper_rgbnir_v1 \
  --run-dir runs/new_method/rse2023_2015_v1/exports/2015_ssa \
  --manifest runs/new_method/rse2023_2015_v1/exports/2015_ssa/export_manifest.json \
  --drive-folder CPIS_RSE2023_2015_RGBNIR_SSA \
  --skip-local-dir runs/new_method/rse2023_2015_v1/pilot_2015_ssa/raw \
  --resume \
  --start-tasks \
  --max-start-tasks 100
```

Refresh status between batches:

```bash
python cpis.py gee export-year \
  --year 2015 \
  --region SSA_Arid_by_Country-shp/SSA_Arid_by_Country.shp \
  --feature-contract paper_rgbnir_v1 \
  --run-dir runs/new_method/rse2023_2015_v1/exports/2015_ssa \
  --manifest runs/new_method/rse2023_2015_v1/exports/2015_ssa/export_manifest.json \
  --skip-local-dir runs/new_method/rse2023_2015_v1/pilot_2015_ssa/raw \
  --refresh-status
```

## 3. Reproduce a Small 2021 Training Set

Use the 2021 anchor layer and 2021 imagery to create one-category COCO chips for
paper-model reproduction.

```bash
python tools/new_method/build_paper_dataset.py \
  --imagery-dir imgs_cache_raw \
  --labels Africa_CPIS-shp/Africa_CPIS_2021.shp \
  --out-root runs/new_method/rse2023_2015_v1/datasets/2021_repro_v1 \
  --chip-size 1024 \
  --chip-overlap 128 \
  --keep-empty
```

This produces:

- `train/images/*.tif`
- `val/images/*.tif`
- `annotations/one_cat_train.json`
- `annotations/one_cat_val.json`
- `dataset_manifest.json`

## 3a. Stage Downloaded 2015 Imagery Into the Canonical Cache

Download 2015 GeoTIFFs from Google Drive to a temporary directory, then stage
them into the canonical local cache:

```bash
python tools/new_method/stage_paper_batch.py \
  --input-dir /path/to/downloaded_2015_batch \
  --out-root runs/new_method/rse2023_2015_v1/pilot_2015_ssa
```

This creates:

- `pilot_2015_ssa/raw/*.tif`
- `pilot_2015_ssa/u8/*_rgbnir_u8.tif`
- `pilot_2015_ssa/_batch_list.txt`
- `pilot_2015_ssa/stage_summary.json`

You can then build a weakly labeled 2015 dataset from the stable pivots:

```bash
python tools/new_method/build_paper_dataset.py \
  --imagery-dir runs/new_method/rse2023_2015_v1/pilot_2015_ssa/raw \
  --labels runs/new_method/rse2023_2015_v1/anchor_truth/overlays/stable_pivots.gpkg \
  --out-root runs/new_method/rse2023_2015_v1/datasets/2015_ssa_stable_v3 \
  --chip-size 1024 \
  --chip-overlap 128 \
  --val-fraction 0.25 \
  --val-sources-file runs/new_method/rse2023_2015_v1/splits/2015_ssa_val_v1/val_tiles.txt
```

## 4. Train the Paper Model on One-Category Data

Adapt the existing Cascade/PointRend config to the one-category dataset without
editing the checked-in config file.

```bash
python tools/new_method/train_paper_model.py \
  --dataset-root runs/new_method/rse2023_2015_v1/datasets/2021_repro_v1 \
  --work-dir runs/new_method/rse2023_2015_v1/models/2021_repro_v1_local \
  --compute-stats \
  --validate
```

Artifacts:

- `resolved_config.py`
- `train_meta.json`
- MMDetection checkpoints/logs in the work dir

For GPU runs on Pod, prefer the Slurm wrapper and set an explicit job name so
the outer `.log` / `.err` files are labeled by experiment:

```bash
sbatch --job-name=cpis_2021_repro \
  --export=CPIS_DATASET_ROOT=runs/new_method/rse2023_2015_v1/datasets/2021_repro_v1,CPIS_TOTAL_EPOCHS=20,CPIS_OPTIMIZER_LR=0.0005,CPIS_GRAD_CLIP_MAX_NORM=5,CPIS_MODEL_TAG=2021_repro_v1_ft \
  tools/new_method/train_paper_model_pod_gpu.slurm
```

To transfer the stronger 2021 model into the 2015 dataset, point the Slurm
wrapper at the 2021 checkpoint explicitly:

```bash
sbatch --job-name=cpis_2015_from_2021 \
  --export=CPIS_DATASET_ROOT=runs/new_method/rse2023_2015_v1/datasets/2015_ssa_stable_v3,CPIS_CHECKPOINT=runs/new_method/rse2023_2015_v1/models/2021_repro_v1_ft_173893/latest.pth,CPIS_TOTAL_EPOCHS=20,CPIS_OPTIMIZER_LR=0.0002,CPIS_GRAD_CLIP_MAX_NORM=5,CPIS_MODEL_TAG=2015_ssa_stable_v3_from_2021 \
  tools/new_method/train_paper_model_pod_gpu.slurm
```

## 4a. Build an Explicit Validation Split for 2015

Before a serious 2015 rerun, generate a fixed validation tile list from the
current raw-tile cache instead of relying on the hash-based source split.

```bash
python tools/new_method/select_val_tiles.py \
  --imagery-dir runs/new_method/rse2023_2015_v1/pilot_2015_ssa/raw \
  --stable-pivots runs/new_method/rse2023_2015_v1/anchor_truth/overlays/stable_pivots.gpkg \
  --change-zones runs/new_method/rse2023_2015_v1/anchor_truth/overlays/change_zones.gpkg \
  --out-root runs/new_method/rse2023_2015_v1/splits/2015_ssa_val_v1
```

This writes:

- `val_tiles.txt`
- `tile_stats.csv`
- `tile_stats.gpkg`
- `selected_val_tiles.gpkg`
- `selection_summary.json`

Then rebuild the 2015 dataset using the explicit validation list:

```bash
python tools/new_method/build_paper_dataset.py \
  --imagery-dir runs/new_method/rse2023_2015_v1/pilot_2015_ssa/raw \
  --labels runs/new_method/rse2023_2015_v1/anchor_truth/overlays/stable_pivots.gpkg \
  --out-root runs/new_method/rse2023_2015_v1/datasets/2015_ssa_stable_v3 \
  --chip-size 1024 \
  --chip-overlap 128 \
  --val-fraction 0.25 \
  --val-sources-file runs/new_method/rse2023_2015_v1/splits/2015_ssa_val_v1/val_tiles.txt
```

## 5. Run Paper-Style Inference

Run the trained checkpoint or an existing paper-model checkpoint on any 4-band
TIFF directory without using the legacy batch wrapper.

```bash
python tools/new_method/run_paper_inference.py \
  --imagery-dir imgs_cache_raw \
  --checkpoint runs/new_method/rse2023_2015_v1/models/2021_repro_v1_ft_173893/latest.pth \
  --out-root runs/new_method/rse2023_2015_v1/inference/2021_repro
```

Artifacts:

- `image_list.txt`
- `segmentation_masks/`
- `inference_summary.json`

## 6. Finalize a Reviewed 2015 Inventory

After manual cleanup of paper-style predictions, normalize the reviewed vector to
the release schema.

```bash
python tools/new_method/finalize_paper_inventory.py \
  --input reviewed_2015_inventory.gpkg \
  --out runs/new_method/rse2023_2015_v1/final/cpis_2015_inventory.gpkg \
  --year 2015 \
  --source-imagery landsat_full_year_2015_rgbnir \
  --model-version rse2023_2015_v1
```

Output fields:

- `det_id`
- `year`
- `country`
- `confidence`
- `qa_status`
- `geometry_status`
- `center_lon`
- `center_lat`
- `area_m2_eq`
- `radius_m_eq`
- `source_imagery`
- `model_version`

## Notes

- `prepare-anchor-truth` writes `overlays/study_area.gpkg` as an anchor-envelope
  diagnostic layer. It is useful for QA, but it is too broad for production
  imagery export because it includes large ocean areas.
- For production-scale 2015 exports, use
  `Africa_Arid_Regions_All-shp/Africa_Arid_Regions_All-shp.shp` or another
  explicit land/arid-region mask as `--region`.
- `paper_rgbnir_v1` exports 4-band `blue,green,red,nir` composites. The default
  `stats_v1` export contract remains unchanged for the Landsat-first classifier
  workflow.
- The one-category training path assumes the anchor layers do not distinguish
  completed vs incomplete pivots. If a future review adds that distinction, a
  two-category dataset can be built separately.
